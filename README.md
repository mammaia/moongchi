# 뭉치 (moongchi)

별것 아닌 것에도 행복한 털뭉치를 바라보는 모바일 힐링 육성 게임.
게임 전체 기준은 GDD(게임 개요서)이며, 설계와 단계 계획은 프로젝트 설계서를 따른다.

## 지금 할 수 있는 것 (1차 프로토타입)

- 현관에서 바라본 원룸 전체 화면 (세로, 2D 임시 그림)
- 뭉치가 아무것도 안 해도 스스로 행동한다: 가만히 있기(두리번), 짧게 이동하기(앞뒤로 넓게), 혼자 놀기, 침대에 올라가 통통 뛰기, 책상 뒤에 숨어 빼꼼
  - 멀리(안쪽) 있으면 작게, 가까이(앞쪽) 오면 크게 보이고, 책상 뒤에 숨으면 책상에 가려진다
  - 아기·강아지처럼 행동이 자주 바뀐다
  - 혼자 놀기는 강아지처럼: 엎드려 엉덩이 흔들기, 폴짝 덮치기, 물어서 던지기, 물고 도리도리, 쫓아가기 (휴지심·양말 임시 그림)
  - 놀던 장난감은 방에 남고, 앱을 나갔다 들어오면 치워져 있다
  - 평소엔 깨어 있고, 앱에 오랜만에 돌아왔을 때와 책상(다이어리)·조리대를 열었을 때만 잠깐 존다
  - 쓰다듬으면 하던 행동(잠 포함)을 멈추고 좋아한다
  - 시간·확률 숫자는 모두 `src/data/balance.ts`의 임시값([가정])
- 뭉치를 톡 누르거나 문지르면 쓰다듬기. 하루 첫 쓰다듬기에만 스파클 +10 (10은 임시값)
- 창문, 침대, 화장실 화살표, 컴퓨터 책상, 조리대, 냉장고, 현관을 누르면 그 부분을 확대하고 설명을 보여준다 (기능은 이후 단계)
- 브라우저를 닫았다 열어도 스파클이 남아 있다
- 카메라: 왼쪽 아래 주황색 버튼을 누르면 지금 방과 뭉치를 그대로 찍는다
  - 스파클 표시·버튼·물건 이름표·보상 반짝이는 사진에 안 나온다. 뭉치 자세는 바꾸지 않는다
  - 찍으면 미리보기가 뜨고 `저장` 또는 `다시 찍기`를 고른다. 찍은 날짜·시간이 함께 저장된다
  - 미리보기에서 틀의 모서리를 끌면 일부만 잘라 저장할 수 있다. 틀 안을 끌면 옮겨지고, `전체로`를 누르면 되돌린다 ([가정] 찍은 뒤 자르기)
- 앨범: 카메라 위 작은 버튼. 날짜별로 모아 보고, 누르면 크게 보고, 지울 수 있다
  - 사진은 기기 브라우저의 IndexedDB에 진행 상황 저장과 따로 저장된다 (`src/core/photoLibrary.ts`)
  - 시크릿 모드처럼 저장소를 못 쓰면 앱을 닫을 때까지만 남는다고 알려 준다

## 휴대폰으로 테스트하기

테스트 링크: https://mammaia.github.io/moongchi/ (GitHub Pages를 켠 뒤부터 열림)

- 주소 끝에 `?dev=1`을 붙이면 오른쪽 위에 DEV 버튼이 생긴다.
  날짜 넘기기, 스파클 0으로, 저장 지우기, 뭉치 행동 바로 시키기(지금 행동 표시)를 할 수 있다.

## 개발자용 명령

```
npm install      # 처음 한 번
npm run dev      # 개발 서버 (같은 와이파이의 휴대폰에서도 열림)
npm test         # 규칙 테스트
npm run e2e      # 화면 테스트 (아이폰·안드로이드 크기)
npm run check    # 빌드 + 전체 테스트
```

## 구조

```
src/core/        공통 기반: 상태 저장소, 이벤트 알림판, 저장(버전 변환), 게임 시계
src/data/        기획 수치표(balance.ts)와 방 배치표(room.ts). 숫자는 여기만 고친다
src/features/    기능별 폴더. 기능끼리는 서로 직접 부르지 않고 이벤트로만 소통
src/scenes/      Phaser 화면 (메인 원룸)
src/ui/          화면 위 HTML (스파클 표시, 설명 시트, 개발자 패널)
tests/unit/      규칙 테스트 (Vitest)
tests/e2e/       화면 테스트 (Playwright)
```
